Lexiora offline dictionary data
================================

Source : Wordset Dictionary (https://github.com/wordset/wordset-dictionary)
License: Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0)
         Portions derived from Princeton WordNet 3.0 (WordNet License).

Format : wordset.jsonl.gz — gzip-compressed JSON Lines. One entry (word sense)
         per line: {"w":<word>,"p":<part of speech>,"m":<meaning>,"e":<example?>}

Curated pack: urdu_wiktionary_pack.json
  English → Urdu word dictionary derived from TWO kaikki.org Wiktionary
  dumps (CC BY-SA 4.0, © Wiktionary contributors):
  1. the Urdu dump (https://kaikki.org/dictionary/Urdu/) — Urdu headwords
     paired with their English glosses (the gloss is used, never the links,
     which leak {{topic|...}} tags like "automotive"/"semantics" and caused
     the old mis-pairs), and
  2. the English dump (https://kaikki.org/dictionary/English/) — each
     English headword's curated Urdu `translations`, which adds common words
     the Urdu dump misses (bench, brake, biology, chemistry, chicken, ...).
     Vulgar/sensitive English headwords are dropped, matching the Urdu-dump
     path.
  Each entry carries part of speech, a WordNet English definition and a usage
  example where available. Regenerated by tools/dictionary/rebuild_dictionary.py
  with common-sense-first Urdu; offensive content, digits and Latin leakage
  are filtered; entries with no usable English body are dropped unless the
  base Wordset dictionary supplies the definition. 5,743 pack headwords
  (~7,700 Urdu-covered words in the merged dictionary; 240 of them get their
  Urdu from the English dump alone).

Corrections pack: zz_curated_corrections.json
  Hand-curated corrections (1,180 entries) for words whose Wiktionary-derived
  English↔Urdu pairing used a rare or technical sense or an awkward meaning
  (e.g. `angel` → سر "head", `breakfast` → حاضری "attendance", `abacus` →
  جنت "heaven",  `semantics` → ضد "stubbornness", `bank` → "sloping land"
  first, `scared` → slang, `union` → میتھن, `participate` → بیٹھنا,
  `courtesan` → آنٹی "aunt", `lesbianism` → چپٹی "flat", `oblique` →
  خزاؤں "taxes"). Each
  entry pins the common, exam-appropriate English definition + simple Urdu
  meaning. The "zz_" prefix makes the exam-pack seeder merge it LAST, so
  these corrections always win over the raw kaikki/wiktionary entries for the
  same headword. Derived from the same CC BY-SA 4.0 Wiktionary lineage as
  urdu_wiktionary_pack.json.

Enrichment pack: 000_wordnet_enrichment.json
  WordNet 3.1 (https://wordnet.princeton.edu) full entries for ~112k
  dictionary words (WordNet License — permissive, redistribution permitted).
  One entry per headword: {"word","partOfSpeech","englishDefinition",
  "synonyms"?, "antonyms"?, "usage"?}. The definition comes from the word's
  MOST FREQUENT WordNet sense (ordered by SemCor counts from cntlist), so the
  common meaning wins over rare/technical senses (bat → the flying mammal, not
  "a turn at bat"); synonyms and antonyms come only from that same sense
  (no cross-sense mixing), and the example sentence is filtered for
  inappropriate content. Regenerated by tools/dictionary/rebuild_dictionary.py.
  The "000_" prefix makes the exam-pack seeder merge it FIRST, so the curated
  packs always win for words they already cover. The Urdu translation of a
  sentence is fetched by the hybrid translator and cached for offline reuse.

Curated packs: exam_words.json, common_words.json, common_words_2.json
  Hand-curated exam / high-frequency word packs (CSS & BPSC oriented).
  exam_words.json carries hand-written synonyms/antonyms/usage/idioms/exam
  notes; common_words* carry simple English + Urdu meanings and a WordNet
  example sentence where available. Hand-written Urdu meanings, usage
  sentences and exam notes are never overwritten.
